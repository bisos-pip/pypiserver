* Key Design Decisions
  - One fqdn, two programs (user, 2026-10-16, option b): pypi-browser at /, the index at /simple/. POST / is
    the upload endpoint and GET / the browser's home page, so the vhost routes / with a map on
    $request_method (in the http context; the map's name carries the fqdn's, to stay unique), not `if`.
    client_max_body_size 200m (nginx's 1m default refuses uploads). pypiserver's --server-base-url would allow
    a prefix instead, but would move the index to /pypi/simple/.
  - Python programs go in /bisos/venv/py3/asc (user); exceptions, only for a demonstrated conflict, in
    /bisos/venv/py3/isolated/<program>/ (user chose "isolated"), named by the program, recording why, moved
    back when the reason is gone. pypi-browser is one: 0.0.12 fails on Starlette 1.x and asc has 1.6.0
    (Airflow's); it declares no bound, so pip and the dry-run guard cannot see the conflict --- only running
    it does. Upstream fix chriskuehl/pypi-browser PR #15.
  - asc: exact pins, no hashes (a shared venv cannot require them), a dry-run guard against changing others'
    packages. isolated: the whole resolved set with hashes, --no-deps.
  - Pins are applied by func-bearing pseudo-packages, not pipPkgsList/pipxPkgsList: bisos.sbom ignores
    versions there and skips installed packages (AI-Outputs.org) --- so bisos.airflow's ver= pin is not
    applied either.
  - pypiserver: --authenticate update (downloads and listing anonymous), --disable-fallback (no redirect to
    pypi.org; use --extra-index-url), no --server (it rejects "waitress"; auto picks waitress when installed,
    otherwise wsgiref, single-threaded).
  - pip needs --trusted-host for a plain-HTTP index on a non-localhost name; carried in pypiserverInfo.
  - htpasswd hashed by passlib with apr_md5_crypt (no bcrypt module needed).
  - twine via pipx (a CLI), at its pin, reinstalled on a bump.
  - Out of chain (under git): the cbm-package-authorship skill (asc/isolated rules, Python install method,
    pitfalls) in /bisos/git/bxRepos/bisos/defaults/ai-templates/mother/_skills/; AI-Outputs.org
    (blee-binders/evolution): bisos.sbom ignores pip/pipx versions.
